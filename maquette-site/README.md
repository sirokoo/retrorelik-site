# RetroRelik — maquette du site

Sauvegarde du 26 septembre 2026. Source de la version publiée : fb9727b435ca1fde5423d5ea9909270dbae01f1a.

Maquette : https://retro-relik-boutique.sirokoo.chatgpt.site

## Ouvrir

Télécharger le dépôt et ouvrir `maquette-site/index.html` dans un navigateur. Aucun outil de compilation nécessaire. Les polices Google nécessitent une connexion Internet.

## Contenu

- `index.html` : structure de la page.
- `style.css` : charte et affichage mobile/ordinateur.
- `app.js` : catalogue, fiches, navigation et cinq langues.
- `admin.js` : simulation de gestion du stock et des marges.
- `theme.js` : mode clair/sombre.
- `images/` : photos, visuels de démonstration et logo.

## Limites

Prototype HTML/CSS/JavaScript, pas encore un thème WordPress/WooCommerce installable. Aucun paiement ni commande réelle. La gestion est une démonstration côté navigateur, sans authentification ni base de données ; les modifications de gestion utilisent sessionStorage. Ne pas y saisir de données confidentielles. Les traductions sont intégrées au code, sans service automatique connecté.

Cette sauvegarde n'établit pas de synchronisation automatique avec la maquette hébergée. L'application de gestion existante reste dans `public/` et `api/`. La charte commune est dans `../docs/CHARTE_GRAPHIQUE.md`.
