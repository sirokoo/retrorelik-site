# RetroRelik — site internet

Dépôt dédié à la maquette du futur site marchand RetroRelik. L'application de gestion des stocks est un projet distinct : https://github.com/sirokoo/stock-brocante.

- `maquette-site/` : code HTML/CSS/JavaScript et images. Ouvrir `maquette-site/index.html` pour consulter la maquette localement.
- `docs/CHARTE_GRAPHIQUE.md` : copie de la charte graphique commune.
- `assets/branding/` : copies des deux fichiers de logo (`retro-relik-logo.jpg` et `retrorelik-logo-horizontal.png`).

Transfert du 26 septembre 2026 depuis stock-brocante, commit ee346aebadf24ed8b36c5ae5d938c758e76826b2. Les fichiers transférés ont été conservés à l'identique. Le README historique dans maquette-site mentionne encore les dossiers public et api de l'ancien dépôt : ils appartiennent uniquement à stock-brocante.

La maquette n'est pas encore un thème WordPress/WooCommerce installable. La gestion est une simulation dans le navigateur, sans authentification ni base de données. Aucun paiement réel. Pas de synchronisation automatique avec le site hébergé.
